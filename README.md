# 倒水挑战 · 无尽模式

一个用单个 HTML 文件实现的倒水排序小游戏，仿手游水排序玩法的无尽模式。无任何外部依赖，浏览器直接打开即玩。

在线游玩：<https://osborn-xiao.github.io/water-sort-endless/>

## 玩法

- 棋盘为 **3 行 × 11 列**，共 33 个瓶子
- 点击一个瓶子选中，再点另一个瓶子，将最上方的液体倒入目标瓶（同色且目标未满才能倒入）
- 瓶子中可能有 **「?」隐藏格**：倒出上层液体后才会显露出下方真实颜色
- 集满 **4 格同色** 的瓶子会自动消失并补充新瓶，得分与倒计时增加
- 倒计时归零即游戏结束

## 特性

- **无尽模式**：连续棋盘，瓶子消逝后新瓶自动补位，直到时间耗尽
- **计分系统**：基础 +100 分/瓶，连续完成可获得连击加成
- **倒计时**：开局 90 秒，每完成一瓶 +3 秒，上限 180 秒
- **历史最高分**：使用浏览器本地存储（localStorage），换浏览器或清缓存会重置
- **手机适配**：竖屏自动旋转为横屏显示，支持触控操作，瓶子可一屏放下无需滚动
- **暂停/重新开始**：右上角图标按钮

## 运行

直接用浏览器打开 `index.html` 即可。

或部署到任何静态托管（如 GitHub Pages）。

## 技术栈

纯 HTML / CSS / JavaScript，单文件实现。
